# TTS Providers for Real-Time German-Language Voice AI Tutoring (2026)

**Scope note on units:** Per-character billing (ElevenLabs, Azure, Google Cloud TTS, Amazon Polly, Fish Audio, MiniMax's published rate) is directly comparable char-for-char. Per-token audio-output billing (OpenAI's `gpt-4o-mini-tts`/Realtime models, Gemini native-audio/TTS-preview models) is NOT directly comparable without a conversion assumption. **Explicit conversion assumptions used throughout this file:**
- Spoken-word rate: 150 words/minute (per assignment).
- Characters per spoken word: 6 (average word + trailing space; used uniformly for English and German text since German words run longer than English, partially offsetting the character-vs-token differences below). → 900 characters/minute → **54,000 characters/hour**.
- Gemini audio tokens: Google explicitly publishes **25 audio tokens per second of output audio** → 90,000 audio tokens/hour. This is an official, stated conversion, not my estimate.
- OpenAI Realtime audio-token/duration ratio (≈600 input tokens/min, ≈1,200 output tokens/min of audio) is **not an OpenAI-published constant** — it is a community/third-party estimate (HackerNoon, forasoft.com) and is flagged as such below.

## Official current pricing (per 1,000 characters / per minute / per token) for each provider

### Takeaway
Per-character pricing across "standard/turbo" tiers clusters tightly around $4–$16 per 1M characters (Google Standard/WaveNet, Azure Neural, Polly Standard/Neural, OpenAI tts-1, Fish Audio, MiniMax Turbo), while "premium/HD/expressive" tiers land at $30–$160 per 1M characters (ElevenLabs Multilingual v2, Google Chirp3-HD/Studio, Polly Generative/Long-Form, MiniMax HD). ElevenLabs and Cartesia primarily sell subscription "credits" rather than a pure metered per-character API rate, though ElevenLabs does publish direct USD-per-1000-characters figures on its API pricing page.

### Cited Findings
- **ElevenLabs**: Official API rates (subscription-independent, billed once included credits are exhausted): Multilingual models = **$0.10 per 1,000 characters**; Flash/Turbo models = **$0.05 per 1,000 characters** — [ElevenLabs API Pricing](https://elevenlabs.io/pricing/api). Subscription plans: Free $0/mo (10k credits), Starter $6/mo (30k credits), Creator ~$22/mo promotional (121k credits), Pro $99/mo (600k credits), Scale $299/mo (1.8M credits, 3 seats), Business $990/mo (6M credits, 10 seats), Enterprise custom — [ElevenLabs Pricing](https://elevenlabs.io/pricing). "1 text character = 1 credit" for v2 Multilingual models; v2.5 Flash/Turbo use "0.5 to 1 credit per character" (discounted) — [ElevenLabs Pricing](https://elevenlabs.io/pricing).
- **Cartesia**: Sells subscription "credits," not a published standalone per-character overage rate. Free $0/mo (20K credits, ~27 min TTS), Pro $5/mo (100K credits, ~133 min), Startup $49/mo (1.25M credits, ~1,667 min), Scale $299/mo (8M credits, ~10,667 min), Enterprise custom — [Cartesia Pricing](https://cartesia.ai/pricing). Voice agent/telephony pricing is published separately: "$0.06 per minute" for agent call duration and "$0.014 per minute" for Cartesia-provided telephony numbers — [Cartesia Pricing](https://cartesia.ai/pricing). No explicit per-character or per-1000-character metered rate was found on the pricing page (gap, see below).
- **OpenAI**: `tts-1` = **$15 per 1M characters** ($0.015/1,000 chars); `tts-1-hd` = **$30 per 1M characters** ($0.030/1,000 chars) — [Burnwise tts-1 pricing](https://www.burnwise.io/ai-pricing/model/tts-1), corroborated by [TextToLab OpenAI TTS Pricing](https://texttolab.com/blog/openai-tts-pricing). `gpt-4o-mini-tts` (token-based, not character-based): **$0.60 per 1M text-input tokens + $12 per 1M audio-output tokens**, cited as ≈$0.015/minute of audio in aggregate — [OpenAI Developer Community thread](https://community.openai.com/t/understanding-gpt-4o-mini-tts-pricing-input-characters-cost/1151816) and [TokenMix](https://tokenmix.ai/blog/gpt-4o-mini-tts-cheapest-tts-api-2026). Realtime API (`gpt-realtime-2.1`, conversational, includes TTS + STT): **$32/1M audio-input tokens, $64/1M audio-output tokens**; mini variant ≈**$10/1M in, $20/1M out** — [Forasoft OpenAI Realtime API Pricing](https://www.forasoft.com/blog/article/openai-realtime-api-pricing). Real-world reported cost: "$0.06–$0.11/min on gpt-realtime-2.1 and $0.02–$0.05/min on the mini" — [HackerNoon](https://hackernoon.com/openai-realtime-api-pricing-in-2026-real-world-data-from-4000-measured-sessions) (self-reported measurement study, not an official OpenAI figure).
- **Google Cloud Text-to-Speech**: Standard voices = **$4 per 1M characters** (4M chars/month free); WaveNet = **$4 per 1M characters** (1M chars/month free); Neural2 = **$16 per 1M characters**; Studio voices = **$160 per 1M characters**; Chirp3-HD = **$30 per 1M characters** (1M chars/month free) — figures consistently reported across [TextToLab](https://texttolab.com/blog/google-cloud-tts-pricing) and multiple other aggregator summaries of the official page. **Caveat**: a direct WebFetch of `cloud.google.com/text-to-speech/pricing` returned only a truncated placeholder in this session, so these numbers are sourced from third-party aggregators reporting the official table rather than a first-hand read of the live page — flagged as a confidence caveat, not a contradiction (multiple independent aggregators agree on the same figures).
- **Gemini native audio / TTS (Google AI)**: `gemini-2.5-flash-preview-tts` = **$10 per 1M audio-output tokens** (paid tier), **$5/1M** batch; `gemini-2.5-pro-preview-tts` = **$20 per 1M audio-output tokens**, **$10/1M** batch; `gemini-3.1-flash-tts-preview` = **$20/1M** paid, **$10/1M** batch; `gemini-2.5-flash-native-audio-preview` (Live API conversational) = **$12 per 1M audio-output tokens**; audio tokens = **25 tokens/second of audio** (official conversion) — [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing). Both TTS-preview models are free in the free tier.
- **Azure AI Speech (TTS)**: Free tier (F0) = 0.5M characters/month free (Neural). Pay-as-you-go: Neural ≈ **$16 per 1M characters**; Neural HD figures conflict across sources — one aggregator states **$22/1M** ("dropped from $30 in March 2026"), another cites **$30/1M**; Custom Neural Voice real-time synthesis ≈ **$24/1M characters** plus separate training-compute-hour and endpoint-hosting-hour charges — [TextToLab Azure TTS Pricing](https://texttolab.com/blog/azure-text-to-speech-pricing). **Caveat**: a direct fetch of the official Azure pricing page returned placeholder "$-" values in this session (the page renders pricing via JS/region selector), so exact current Neural HD pricing should be re-verified directly on `azure.microsoft.com/pricing/details/cognitive-services/speech-services/` before committing to a number — flagged as an open gap.
- **Amazon Polly**: Standard voices = **$4.00 per 1M characters** (5M chars/month free); Neural voices = **$16.00 per 1M characters** (1M chars/month free, first 12 months); Long-Form voices = **$100.00 per 1M characters** (500K chars/month free, first 12 months); Generative voices = **$30 per 1M characters** (100K chars/month free, first 12 months) — [AWS Polly Pricing](https://aws.amazon.com/polly/pricing/) (official page, fetched directly).
- **Fish Audio**: Pay-as-you-go API bills **per UTF-8 byte**: for Latin-script text (English, German) 1 character ≈ 1 byte, so effectively **$15 per 1M characters** ($0.015/1,000 chars); for CJK scripts each character is 3 bytes, tripling the effective per-character cost — [Smallest.ai Fish Audio Pricing summary](https://smallest.ai/blog/fish-audio-pricing-plans-api-billing-commercial-use-in-2026), [TextToLab Fish Audio Pricing](https://texttolab.com/blog/fish-audio-pricing). Subscription: Free (8,000 credits/month, personal use only, no commercial rights); Plus $5.50/mo promotional (list price $20/mo) for 200 minutes of S1/S2 generation + commercial rights; Pro $150/mo list price. ~600–625 credits per minute of generation.
- **MiniMax**: Official platform pricing per one source: **$100 per 1M characters for HD models** ($0.10/1,000 chars), **$60 per 1M characters for Turbo models** ($0.06/1,000 chars) — [Puter MiniMax API Pricing breakdown](https://developer.puter.com/tutorials/minimax-api-pricing/). **Source conflict flagged**: third-party reseller platforms (fal.ai, WaveSpeedAI, Together AI) quote materially lower rates for specific model versions — e.g. "MiniMax Speech 02 HD pricing is $0.05 per 1,000 characters," "Speech 2.5 Turbo Preview costs $0.04/1000 chars," "Speech 2.8 Turbo... $0.04" — these are reseller/aggregator prices, not MiniMax's own platform price, and should not be treated as interchangeable with the official `platform.minimax.io` rate card. Official page: [MiniMax Audio Subscription pricing](https://platform.minimax.io/docs/guides/pricing-speech) (not independently re-verified by direct fetch in this session — treat the $100/$60 per-1M figures as the more authoritative "official" number pending direct confirmation).

### Inferences
- For a startup optimizing pure per-character cost among character-billed providers, Google Standard/WaveNet ($4/1M) and Amazon Polly Standard ($4/1M) are the cheapest, but these are older-generation, lower-expressiveness voices; among "usable for a tutoring persona" voices, OpenAI tts-1 ($15/1M) and Fish Audio (~$15/1M) undercut ElevenLabs Flash ($50/1M) and Azure/Polly Neural (~$16/1M... note Azure/Polly Neural at $16/1M is actually cheaper than ElevenLabs Flash) by a wide margin.
- Cartesia's lack of a published standalone per-character rate makes it hard to directly compare against metered competitors; its plan-derived $/minute (see cost-per-hour section) implies a rate roughly in between OpenAI tts-1 and ElevenLabs Flash, but this is inferred from plan allocations, not an official metered price.

### Gaps
- Cartesia's official per-character (or per-1,000-character) overage/metered price, if one exists beyond the credit-plan model, was not found on its pricing page.
- Azure Neural HD's exact current per-1M-character price is unconfirmed at first-hand (official page returned placeholders in-session); the $22 vs $30 figures conflict across secondary sources and need direct re-verification.
- MiniMax's exact current official per-model (Speech-02 vs Speech-2.5 vs Speech-2.8) pricing structure is inconsistently reported across the official platform vs. reseller platforms; the specific model-to-price mapping on `platform.minimax.io` was not independently confirmed by direct page fetch in this session.

## Low-latency streaming support and published time-to-first-audio-byte

### Takeaway
ElevenLabs Flash v2.5 and Cartesia Sonic are the two providers with explicit sub-100ms latency claims and are purpose-built for conversational/real-time use; OpenAI's `tts-1`/`gpt-4o-mini-tts` and Google/Azure Neural voices support streaming but publish (or are independently benchmarked at) closer to 300ms–1s time-to-first-byte; premium/HD tiers from every vendor (ElevenLabs Multilingual v2/v3, Google Studio/Chirp3-HD, Azure DragonHD) are measurably slower and in some cases explicitly not recommended for real-time use.

### Cited Findings
- **ElevenLabs Flash v2.5**: model inference time ≈75ms; a vendor claim of "e2e 135ms time to first byte audio latency" is cited as "the best score in the field," though actual end-to-end TTFB varies with network/location — [ElevenLabs Latency docs](https://elevenlabs.io/docs/eleven-api/concepts/latency), corroborated by third-party summary [Waboom AI](https://www.waboom.ai/blog/elevenlabs-v3-vs-flash-voice-agents). ElevenLabs explicitly states v3 "can't do real-time" and recommends staying on Flash v2.5 for real-time/conversational use cases, reserving Multilingual v2 for pre-recorded, higher-fidelity content — [Waboom AI](https://www.waboom.ai/blog/elevenlabs-v3-vs-flash-voice-agents).
- **Cartesia Sonic**: vendor claims ≈90ms time-to-first-byte for standard Sonic, and "≈40ms TTFB on the Turbo variant" for Sonic 3.5, built on a state-space-model architecture (not a transformer) specifically to minimize latency — [invideo.io Cartesia Sonic overview](https://invideo.io/blog/cartesia-sonic-ai-voice/). An independent-sounding secondary claim states "real-world latency measures ~166–190ms; sub-90ms is a vendor model-latency claim" — i.e., the vendor number is model-compute-only, not full round-trip — [same source, cross-referencing dograh.com TTFB comparison](https://www.dograh.com/feeds/blog/tts-time-first-byte). Cartesia Sonic-3.6 is described as topping "both Artificial Analysis Speech Arenas" as of August 2026 — [MarkTechPost, Aug 18 2026](https://www.marktechpost.com/2026/08/18/cartesia-ships-sonic-3-6-a-streaming-tts-model-that-now-leads-both-artificial-analysis-speech-arenas/).
- **OpenAI**: `tts-1` streams audio and is reported (third-party, not an official OpenAI number) at roughly "0.5 second time-to-first-byte in testing" / "sub-1-second latency"; `gpt-4o-mini-tts` is described as achieving "sub-second latency under normal conditions" for short utterances, with time scaling roughly linearly with input length for longer text — [The Neural Base, OpenAI TTS course notes](https://theneuralbase.com/openai/learn/intermediate/tts-pricing-and-latency/). OpenAI has not published an official first-party TTFB benchmark number for any TTS model as of this research.
- **Independent cross-vendor benchmark**: a 2025/2026 benchmark (BOTfriends) comparing Google and Microsoft TTS found "Google Neural2 and Microsoft Neural" voices had the lowest latency of the sets tested, "Google's Neural2-G and Standard-D voices performing exceptionally well," while "Google Chirp3-HD voices had the highest latency of up to 3.5 seconds for long messages" and "Microsoft's DragonHDLatestNeural voices were similarly slow at 354ms+ for short messages" — [BOTfriends TTS Latency Report](https://botfriends.de/en/blog/tts-latency-benchmark-2025-google-vs-microsoft-voices-fuer-phonebots/). This is a genuinely independent third-party benchmark (not a vendor-published number) and directly supports the pattern that premium/HD tiers trade latency for quality across vendors, not just at ElevenLabs.
- **General industry guidance**: "Voice agents require sub-300ms time-to-first-byte to maintain natural dialogue flow, with delays beyond this threshold creating awkward pauses" — [Picovoice, TTS Latency blog](https://picovoice.ai/blog/text-to-speech-latency/), a vendor-neutral explainer of why TTFB (not total generation time) is the metric that matters for conversational apps.
- **Gemini Live API**: architected specifically for low-latency native audio dialog — "a unified, low-latency, native audio architecture where the Gemini 2.5 Flash Native Audio model processes raw audio natively through a single, low-latency model" — but no specific numeric TTFB figure was found published by Google — [Gemini Live API capabilities](https://ai.google.dev/gemini-api/docs/live-api/capabilities).

### Inferences
- Only ElevenLabs Flash and Cartesia Sonic have vendor-published sub-100ms-class TTFB claims explicitly marketed for real-time voice agents; both caveat that real-world end-to-end latency (network, buffering) pushes actual perceived latency higher (Cartesia's own ecosystem discussion cites ~166–190ms real-world vs a ~90ms vendor claim).
- For a German tutoring app, "premium" tiers (ElevenLabs Multilingual v2/v3, Google Studio/Chirp3-HD, Azure DragonHD) should be reserved for non-time-critical moments (e.g., a pre-generated welcome message, a graded feedback summary) rather than live back-and-forth dialogue, based on both vendor guidance (ElevenLabs explicitly) and independent benchmark data (BOTfriends showing Chirp3-HD/DragonHD are the slowest tiers tested).

### Gaps
- No official first-party TTFB benchmark numbers were found published by OpenAI, Google Cloud TTS, Azure, Amazon Polly, Fish Audio, or MiniMax — all numeric latency claims for those providers in this section are third-party/community-sourced, not vendor guarantees.
- No latency figures (vendor or independent) were found specifically for Amazon Polly, Fish Audio, or MiniMax at all — treat their real-time suitability as unverified/not publicly benchmarked.

## German-language voice quality: support level, demos, and language-specific notes

### Takeaway
Every provider in scope lists German as a supported language, but none of the pricing/model pages found explicitly labels German with a discrete "full support" vs. "beta" quality flag; the more useful public signal is (a) which model tier a vendor recommends for multilingual/German use and (b) documented systemic quality caveats (e.g., accent bias) that apply to German along with other non-English languages.
### Cited Findings
- **ElevenLabs**: German is included in Multilingual v2's documented set of 29 supported languages; Flash v2.5 supports 32 languages (real-time optimized); Eleven v3 supports 74 languages but with an 8x lower character limit per request (5,000 vs 40,000 chars) and is described as not suitable for real-time use — [Deepgram, ElevenLabs Languages vs Accents](https://deepgram.com/learn/elevenlabs-languages-vs-accents-support), [ElevenLabs Models docs](https://elevenlabs.io/docs/overview/models). A documented systemic caveat: "default voices carry English pronunciation into all languages due to training data bias" (example given for Spanish/Dutch, not specifically German, but described as a general multilingual-model issue) — [Deepgram](https://deepgram.com/learn/elevenlabs-languages-vs-accents-support). ElevenLabs positions Multilingual v2 as "most life-like, emotionally rich... best for voiceovers, audiobooks" vs. Flash v2.5 for real-time/conversational use — same source.
- **Cartesia**: German was one of the first languages added when Sonic Multilingual launched (alongside French, Spanish, Portuguese, Chinese, Japanese) — [Cartesia official X/Twitter announcement](https://x.com/cartesia_ai/status/1805338654010916913), later expanded; Sonic-3.6 is now described as supporting 44 languages natively, with German listed explicitly among them — [Cartesia language support](https://cartesia.ai/all-languages) (per search-result excerpt; not independently fetched in full). No German-specific quality caveats or demos were found in this research pass.
- **OpenAI**: No language-specific (German) quality documentation was found for tts-1/tts-1-hd/gpt-4o-mini-tts in this research pass — OpenAI's TTS docs describe multilingual capability generally but a German-specific support statement was not located. **Gap** (see below).
- **Google Cloud TTS / Gemini**: Not directly confirmed by first-hand page read in this session, but Google's TTS voice families (Neural2, Studio, Chirp3-HD) are broadly documented elsewhere as covering German with multiple voice options; the Gemini Live API "supports 70 languages including German, and native audio models automatically detect and switch languages" — [search-result summary of Gemini Live API docs](https://ai.google.dev/gemini-api/docs/live-api/capabilities). Native audio dialog is also described as offering "30 HD voices in 24 languages" with affective/emotional responsiveness — same source cluster.
- **Azure**: No German-specific quality statement was retrieved in this pass (the official pricing page did not render German-language notes, and searches focused on pricing rather than voice-quality documentation). **Gap** (see below) — Azure is broadly known to offer numerous German (de-DE, de-AT, de-CH) neural voices, but this was not freshly verified with a citation in this research pass.
- **Amazon Polly**: German-specific voices confirmed: **Vicki** (de-DE, available as Neural and as Generative), **Daniel** (de-DE, available as Generative), **Lennart** (de-DE, Generative), and **Sabrina** (de-CH, Generative) — [AWS Polly Generative Voices docs](https://docs.aws.amazon.com/polly/latest/dg/generative-voices.html), [AWS "Amazon Polly Launches a new German Neural voice"](https://aws.amazon.com/about-aws/whats-new/2021/06/amazon-polly-launches-a-new-german-neural-text-to-speech-voice) (note: this specific announcement is from 2021 — flagged as an older source; German neural/generative voice coverage has evidently expanded since). Generative voices (including the German ones) are currently available only in specific AWS regions: "Europe (London), Canada (Central), and Europe (Zurich)" — [Oreate AI Blog summary of AWS Polly Generative Voices](https://www.oreateai.com/blog/bringing-text-to-life-the-magic-of-amazon-pollys-generative-voices/cfbf1c39825e15a415345bd851828d96).
- **Fish Audio**: German is explicitly listed as one of Fish Audio's supported languages and classified as a "Tier 2" language (alongside Korean, Spanish, Portuguese, Arabic, Russian, French) with "approximately 20k hours of training data" cited for German in Fish Speech V1.5 — [search-result summary citing Fish Audio model docs](https://docs.fish.audio/developer-guide/models-pricing/models-overview). The newer Fish Audio S2 Pro model is described as trained on "over 10 million hours of audio data covering more than 80 languages," but no German-specific breakdown for S2 was found.
- **MiniMax**: German is listed among supported languages across MiniMax's Speech-01 ("11 languages, including Mandarin, English, German, French, and Spanish"), Speech-02 series (German under "European & Other Languages"), and newer Speech-02 HD/Turbo models ("30+ languages including German") — [search-result summary of MiniMax model docs](https://www.minimax.io/news/speech-02-series). No German-specific quality/MOS data was found.

### Inferences
- German is treated as a "mainstream" supported language by every provider surveyed (none flags it as experimental/beta), but only ElevenLabs' documentation surfaces an explicit general caveat (English-accent bias in multilingual output) that a startup should specifically listen-test for in German before committing.
- Because no provider publishes a German-specific MOS (mean opinion score) or a German-only demo comparison, the only reliable way to select a German voice is a manual/blind listening test across 3-4 shortlisted providers' German demo voices — this was not done as part of this text-based research pass and is a clear next step (see Gaps).

### Gaps
- No provider-published or independent MOS/quality score specific to German was found for any of the eight providers.
- No direct fetch of any provider's German voice sample/demo audio was performed in this research (text-based research; audio quality cannot be assessed via search/fetch tools) — a human listening test is required before final vendor selection.
- Azure's and OpenAI's German-specific language support documentation was not directly retrieved in this pass (time/tool-budget constraint) — only their general multilingual/pricing pages were reviewed.

## Fast/turbo tier vs. premium/highest-quality tier: cost and capability difference (same provider)

### Takeaway
ElevenLabs offers the cleanest documented example: Flash/Turbo is exactly half the price of Multilingual v2 per character ($0.05 vs $0.10 per 1,000 chars) while also being explicitly the only tier recommended for real-time use; Google Cloud shows the widest spread (Standard $4/1M → Chirp3-HD $30/1M → Studio $160/1M, a 40x range); MiniMax's official Turbo-vs-HD spread is a clean ~1.67x ($60 vs $100 per 1M chars); Cartesia does not expose a comparable same-provider tier price split in its public pricing page.

### Cited Findings
- **ElevenLabs**: Flash/Turbo = $0.05/1,000 chars vs Multilingual v2 = $0.10/1,000 chars — an exact **2x price difference** — [ElevenLabs API Pricing](https://elevenlabs.io/pricing/api). Latency difference: Flash ≈75ms model-inference / ≈135ms e2e TTFB vs. Multilingual v2/v3 with no comparable real-time claim (v3 explicitly stated as unable to do real-time) — [ElevenLabs Latency docs](https://elevenlabs.io/docs/eleven-api/concepts/latency); [Waboom AI](https://www.waboom.ai/blog/elevenlabs-v3-vs-flash-voice-agents).
- **Google Cloud TTS**: Standard/WaveNet $4/1M chars → Neural2 $16/1M (4x) → Chirp3-HD $30/1M (7.5x over Standard) → Studio $160/1M (40x over Standard) — [TextToLab Google Cloud TTS pricing summary](https://texttolab.com/blog/google-cloud-tts-pricing). Independently, the BOTfriends benchmark found Chirp3-HD to be the *slowest* tier tested (up to 3.5s latency for long messages) — [BOTfriends](https://botfriends.de/en/blog/tts-latency-benchmark-2025-google-vs-microsoft-voices-fuer-phonebots/) — meaning Google's priciest tier is also documented as its least real-time-friendly, the inverse of what a "premium for important moments" strategy would want unless used only for pre-generated (non-live) audio.
- **Amazon Polly**: Standard $4/1M → Neural $16/1M (4x) → Generative $30/1M (7.5x) → Long-Form $100/1M (25x) — [AWS Polly Pricing](https://aws.amazon.com/polly/pricing/).
- **MiniMax**: Turbo $60/1M chars vs HD $100/1M chars — **1.67x price difference** (official platform pricing) — [Puter MiniMax pricing breakdown](https://developer.puter.com/tutorials/minimax-api-pricing/).
- **Azure**: Neural ≈$16/1M vs Neural HD reported as either $22/1M or $30/1M depending on source (see pricing section caveat) — implying roughly a **1.4x–1.9x** spread, unconfirmed precisely — [TextToLab Azure pricing](https://texttolab.com/blog/azure-text-to-speech-pricing).
- **OpenAI**: tts-1 $15/1M vs tts-1-hd $30/1M — an exact **2x price difference** — [Burnwise](https://www.burnwise.io/ai-pricing/model/tts-1). gpt-4o-mini-tts uses a fundamentally different (token-based) pricing model, making a direct multiplier vs. tts-1/tts-1-hd not apples-to-apples without the character/token conversion caveat stated at the top of this document.
- **Gemini**: `gemini-2.5-flash-preview-tts` $10/1M audio-output tokens vs `gemini-2.5-pro-preview-tts` $20/1M — exact **2x price difference** — [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing).
- **Cartesia**: No same-provider fast-vs-premium price split is published; Sonic and Sonic Turbo/3.5/3.6 appear to be sequential model-version upgrades (each faster and higher quality than the last) rather than a simultaneously-offered two-tier product, and all are billed through the same credit system regardless of which Sonic version is used — [Cartesia Pricing](https://cartesia.ai/pricing), [invideo.io Sonic overview](https://invideo.io/blog/cartesia-sonic-ai-voice/).
- **Fish Audio**: Only one metered rate ($15/1M bytes ≈ chars for Latin scripts) was found; no separate "fast vs. premium" per-character price split was found in this research pass (subscription tiers differ by minutes-included and commercial rights, not by a stated per-character quality/speed tier split) — [Smallest.ai Fish Audio pricing](https://smallest.ai/blog/fish-audio-pricing-plans-api-billing-commercial-use-in-2026).

### Inferences
- A "cheap/fast for casual, premium for important moments" dual-tier strategy is most cleanly executable with ElevenLabs (2x price, clear real-time-vs-not distinction) or Gemini TTS-preview (2x price, Flash vs Pro) since both explicitly document which tier is fast/real-time-capable vs. which is higher-quality/non-real-time.
- Google Cloud's premium tier (Chirp3-HD/Studio) is a poor fit for the "important moment spoken live" use case specifically because it is documented as slower, not just pricier — it would suit a "pre-generate an audio welcome/summary asynchronously" use case better than a live premium reply.

### Gaps
- No confirmed same-provider fast-vs-premium price split was found for Cartesia or Fish Audio.
- No independent, apples-to-apples MOS/quality score comparing each provider's own fast vs. premium tier was found (all quality comparisons found were cross-provider, not within-provider).

## Rough cost per hour of continuous TTS output (150 words/min) — top candidates, cheap vs. premium tier

### Takeaway
Using this document's stated conversion (150 wpm × 6 chars/word = 54,000 characters/hour), the four most realistic candidates for a real-time German tutoring voice product — ElevenLabs, Cartesia, OpenAI, and Google (Cloud TTS + Gemini) — range from roughly **$0.20–$0.90/hour** on their cheapest usable tier to **$1.60–$5.40/hour** on their premium tier. All figures below are arithmetic derived from the official/cited per-unit rates above, not separately published "per-hour" numbers from any vendor.

### Inferences
- On a pure cost-per-hour basis for the "cheap/fast" tier, **Google Cloud Standard/WaveNet and Amazon Polly Standard (~$0.22/hr) are cheapest**, followed by **OpenAI tts-1 (~$0.81/hr) and Fish Audio (~$0.81/hr)**; **ElevenLabs Flash (~$2.70/hr) and MiniMax Turbo (~$3.24/hr) are the most expensive "fast" tiers** among the candidates compared, roughly 3–15x the cheapest options — quality/latency/language-robustness differences (not assessed by audio listening in this pass) would need to justify that premium.
- For the "premium" tier, cost ranges roughly 2x (ElevenLabs, Azure, MiniMax, Gemini) to 40x (Google Studio) above each provider's own cheap tier; Google Studio and Amazon Polly Long-Form are outliers priced for narration/production use rather than live conversational replies.
- Given the pattern in the latency section (premium/HD tiers being slower, sometimes explicitly not real-time-capable), the dual-tier "cheap/fast for casual, premium for important" strategy is architecturally sound for ElevenLabs (Flash for live dialogue, Multilingual v2 for a pre-rendered "important moment" clip) and for Gemini (Flash TTS-preview live, Pro TTS-preview or native-audio for special content), but is a poor fit for Google Cloud TTS Studio/Chirp3-HD as a live "important moment" voice specifically because of its documented 3.5-second latency — it would need to be pre-generated asynchronously, not spoken live even for "important" moments.

### Gaps
- These are back-of-envelope calculations built on this document's stated 6-chars/word and 25-tokens/sec conversions — no vendor publishes an official "$/hour of continuous speech" figure, so none of these numbers should be treated as vendor-guaranteed pricing; they are only as accurate as the underlying per-unit rates and the character/token conversion assumptions.
- Real conversational usage is bursty, not continuous, so actual monthly cost for a tutoring app depends heavily on average session length and turn-taking patterns, which is outside the scope of this per-hour estimate.

## Voice cloning / custom-voice capability and cost

### Takeaway
ElevenLabs, Azure, and Amazon Polly all offer branded/custom-voice options at meaningfully different investment levels: ElevenLabs bundles Instant Voice Cloning starting at its $5–6/month Starter tier and gates higher-fidelity "Professional Voice Cloning" behind its ~$22/month Creator tier and up; Azure's Custom Neural Voice is a metered production service with separate training-compute and hosting fees rather than a flat add-on; Fish Audio also offers voice cloning as part of its paid/commercial tiers. Cartesia offers "Instant voice cloning" from its Pro ($5/mo) tier and "Pro voice cloning" from Startup ($49/mo) up.

### Cited Findings
- **ElevenLabs**: **Instant Voice Cloning** is available starting on the **Starter plan ($5–6/month)** — described as needing "only a short audio sample," fast to set up, but "may sound less stable during long narration sessions" — [search-result summary of ElevenLabs voice cloning pricing pages](https://cognitivefuture.ai/elevenlabs-voice-cloning/), [ElevenLabs Pricing](https://elevenlabs.io/pricing). **Professional Voice Cloning** requires the **Creator plan (~$22/month) or higher**, uses more training audio, and is described as producing "significantly higher fidelity results" with "the voice remaining more consistent across longer scripts" — same sources. No separate flat per-clone fee beyond the plan price was found; cloned voices consume the plan's normal per-character credit rate for subsequent generation.
- **Cartesia**: Plan feature list shows **"Instant voice cloning"** unlocked at the **Pro tier ($5/month)** and **"Pro voice cloning"** unlocked at the **Startup tier ($49/month)** — [Cartesia Pricing](https://cartesia.ai/pricing). No separate per-clone dollar fee beyond the subscription was found; usage of cloned voices draws from the plan's normal credit allocation.
- **Azure**: **Custom Neural Voice** (formerly Custom Voice) is priced as a separate line item from prebuilt Neural voices: synthesis is billed per 1M characters (reported ≈$24/1M for real-time Custom Neural, per the earlier pricing-section citation), **plus** "Voice model training per compute hour (capped at a maximum amount)" and "Endpoint hosting per model per hour" — i.e., a custom voice carries ongoing hosting cost even when idle, not just a one-time or per-character fee — [TextToLab Azure TTS pricing](https://texttolab.com/blog/azure-text-to-speech-pricing) / official pricing page structure (fetched directly, though exact dollar figures for training/hosting were rendered as placeholders in this session — see Gaps). Azure separately offers **Personal Voice** (a lighter-weight custom-voice feature) with "Voice creation: Free" and per-1,000-profile monthly storage charges, distinct from the heavier Custom Neural Voice production pipeline — same source.
- **Amazon Polly**: A **Brand Voice** custom-voice program exists per general AWS documentation structure (Polly's generative-voice family and custom-voice options are documented separately from the standard per-character API), but specific current pricing for a Polly custom/brand voice was **not retrieved** in this research pass — flagged as a gap.
- **Fish Audio**: Voice cloning is positioned as a core product feature ("Free Text To Speech & Free Voice Cloning" is Fish Audio's own tagline) with commercial-use rights (including presumably commercial use of cloned voices) unlocked starting at the **Plus plan (~$5.50/month promotional, $20/month list)** — [Fish Audio homepage tagline / Smallest.ai pricing summary](https://smallest.ai/blog/fish-audio-pricing-plans-api-billing-commercial-use-in-2026). Exact incremental cost of the cloning step itself (vs. ongoing generation cost) was not found as a separate line item.
- **MiniMax and Cartesia's "Pro voice cloning" tier of quality**, **OpenAI**, and **Google Cloud/Gemini**: No public voice-cloning / custom-voice product was found for OpenAI's or Google's consumer/developer TTS APIs in this research pass (Google Cloud TTS's "Instant Custom Voice" feature was named in the assignment's suggested scope but its current pricing/availability was not independently confirmed here — flagged as a gap). MiniMax's cloning capability was not investigated in this pass beyond the general model docs.

### Inferences
- If a branded/consistent "tutor voice" matters, **ElevenLabs Professional Voice Cloning (~$22/month plan tier)** or **Cartesia Pro voice cloning (~$49/month Startup plan)** appear to be the most turnkey, subscription-bundled paths found; **Azure Custom Neural Voice** is a heavier, more production-grade (and likely more expensive in aggregate once training + hosting are included) option better suited to an enterprise-scale, high-volume deployment than an early-stage startup's MVP tutor voice.
- A startup wanting a distinct, ownable tutor voice without heavy upfront investment should likely prototype with ElevenLabs' or Cartesia's Instant/Pro voice cloning before considering Azure's Custom Neural Voice pipeline, given the latter's separate ongoing hosting-per-hour cost structure.

### Gaps

- Amazon Polly's Brand Voice / custom-voice pricing was not found in this research pass.
- Google Cloud's "Instant Custom Voice" feature (named in the assignment's suggested source list) was not independently investigated or priced in this pass.
- OpenAI's and Gemini's voice-cloning/custom-voice capabilities (if any exist beyond fixed preset voices) were not confirmed either way in this research pass.
- No confirmation was found on whether any provider's voice-cloning terms explicitly restrict or permit cloning a live human tutor's voice for a commercial education product (a legal/consent question the startup should separately verify in each provider's ToS before proceeding) — noted as an important follow-up, not covered by pricing pages.
