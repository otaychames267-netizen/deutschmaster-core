# Product demo video (Lemon Squeezy review, 2026-10-14)
Playwright (`recordVideo`) + ffmpeg. `rec-public.mjs` records the PUBLIC pages of the live site (no account, nothing submitted); `rec-student.mjs` records the signed-in student area on a LOCAL build (`bun run build` with the VITE_ vars exported, `node .output/server/index.mjs` on :3998) using a disposable demo user + subscription created with the service role (session injected into localStorage `sb-<ref>-auth-token`, nothing typed) and deleted afterwards (`e2e-setup.mjs teardown`). Captions are in-page overlays; silent video. Concat: scale 1280x720, 25 fps, `concat`, libx264 crf 23, silent AAC track.
Paths in the scripts point at the session scratchpad — adjust `SP` and the Playwright `createRequire` base before reuse.
