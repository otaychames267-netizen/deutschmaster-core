# Sprachbausteine Teil 1 — skipped duplicates (identical test content)

Policy (user, 2026-07-05): skip a repeated page ONLY if blanks + options + answer key +
order are 100% identical to an already-built exercise AND it is the same letter/text.
Any real difference in a blank, option, answer, or wording → keep as a separate exercise
("X 2"). Formatting/color/font differences alone do NOT make a separate exercise.

GOVERNING RULE for اساسي/معدل repeats (user, 2026-07-05): if a repeat has the SAME text,
SAME gap positions, and SAME answer letters, and differs ONLY in corrupted/erroneous
option text (spelling errors or nonsense substitutions) → it is a DUPLICATE; keep the
cleaner copy, SKIP the corrupted one. Reserve a separate "X 2" ONLY for pairs that blank
DIFFERENT words (different gap positions), e.g. Karin/Karin 2, Andrea/Andrea 2,
Herr Dr. Dobromil/Herr Dr. Moosberger.
